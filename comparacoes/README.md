# Materiais reais de comparação

Coloque aqui somente imagens de **um mesmo quadro antes e depois da edição**.

- Original: frame genuíno do bruto, sem o acabamento demonstrado.
- Final: frame equivalente do trabalho entregue.
- Prefira WebP 960 × 540 px com tamanho reduzido.
- Não altere artificialmente um vídeo finalizado para fingir que é a versão original.
- Liste o par no arquivo raiz `comparacoes.json`.

Enquanto `comparacoes.json` estiver vazio, nenhum comparador aparecerá publicamente.
