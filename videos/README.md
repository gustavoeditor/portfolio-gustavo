# Vídeos do portfólio

Envie os arquivos de vídeo para esta pasta pelo GitHub: **Add file → Upload files**.

- Prefira `.mp4` com codec H.264 e áudio AAC.
- Use nomes curtos, sem espaços e sem acentos, por exemplo `cs2-cinematic-inferno.mp4`.
- No painel `/gerenciar-projetos.html`, cadastre o caminho como `videos/cs2-cinematic-inferno.mp4`.
- Vídeos grandes deixam o repositório pesado. Para arquivos grandes, use um host de vídeo público e cole o link no painel.
