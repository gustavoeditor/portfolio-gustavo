# Imagens de canais
Coloque aqui apenas logos de canais em que Gustavo realmente trabalha ou já trabalhou, com autorização para exibir o logo no portfólio.

- Recomendações: WebP quadrado (160 × 160 a 320 × 320 pixels), menos de 80 KB
- Use nomes simples, como `meu-canal.webp`
- Depois, informe o caminho em `canais.json`, como `"imagem": "canais/meu-canal.webp"`

Se não houver logo, não é necessário acrescentar nada. O site exibe a inicial do nome.
